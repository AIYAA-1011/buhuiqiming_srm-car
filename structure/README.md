# 整车结构图纸

## 图纸版本与装配说明

[下载整车结构图纸（ZIP）](整车图纸.zip)

整车结构在中期测评后整体方案基本未变，因此本次提交沿用中期测评图纸。队伍说明，实物后续仅有以下局部调整：

1. 部分螺纹孔和通孔的孔径调整，便于装配。
2. 夹爪齿轮调整。
3. 小臂长度略微增加。

这些变更作为最终实物与中期图纸的差异记录；本次归档不表示压缩包已逐项同步上述改动，复现加工前需核对实际孔径、齿轮与臂长。

### 未提供完整总装的原因

图纸未完成整车总装配，原因沿用中期测评说明：PWM舵机模型并非理想长方体，模型几何使CAD装配和配合处理较困难。本包按零件图纸归档，不作为完成干涉检查的总装模型；这与实车已完成装配是两件不同的事。

压缩包原样保存，共31个条目，包含SolidWorks零件文件与STEP文件。本次未使用CAD软件打开或进行装配、尺寸和干涉验证。
