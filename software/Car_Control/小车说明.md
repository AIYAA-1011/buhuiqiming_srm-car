# 麦克纳姆轮取矿小车说明

---

# 一、系统概述

## 1.1 硬件组成

| 部件 | 规格 | 接口 |
|---|---|---|
| 主控 | STM32F103RCT6，LQFP64，256 KB Flash | — |
| 底盘电机 ×4 | 12 V 直流减速电机，13 线编码器，减速比 1:30 | DRV8874 |
| 轮组 ×4 | 麦克纳姆轮，直径 60 mm，X 型辊子 | — |
| 机械臂 | 5 路舵机：大臂、小臂、腕俯仰、腕旋转、夹爪 | PCA9685（I2C2） |
| 无线通信 | SI24R1 / nRF24L01+ | SPI1 |
| 显示单元 | OLED SSD1315，128×64 | I2C1，地址 0x3C |
| 电量检测 | INA226，采样电阻 3 mΩ | I2C1，地址 0x40 |
| 供电 | 3S 锂离子 18650，1800 mAh，12.6 V / 8.25 V | — |

## 1.2 软件架构

| 任务 | 优先级 | 周期 | 功能 |
|---|---|---|---|
| SafetyTask | Realtime | — | 安全监控（预留） |
| MotorTask | High | 20 ms | 电机驱动、编码器采样、速度闭环、运动学解算 |
| RemoteTask | AboveNormal | 2 ms | 无线数据接收、链路监控、状态指示 |
| ArmTask | Normal | 20 ms | 舵机控制、预设动作、遥杆映射 |
| DisplayTask | BelowNormal | 200 ms | 显示单元刷新 |

# 二、遥控器

## 2.1 摇杆功能

### 底盘模式

| 摇杆 | 功能 | 最大输出 |
|---|---|---|
| 右摇杆 纵向 `ry` | 前进 / 后退 | 0.50 m/s |
| 右摇杆 横向 `rx` | 左右平移 | 0.50 m/s |
| 左摇杆 横向 `lx` | 原地旋转 | 1.50 rad/s |

平移与前后方向的合速度进行等比例限幅，任何方向的合成速度上限为 0.50 m/s。

### 机械臂模式

| 摇杆 | 控制对象 |
|---|---|
| 右摇杆 横向 `rx` | 大臂升降 |
| 右摇杆 纵向 `ry` | 小臂伸缩 |
| 左摇杆 横向 `lx` | 腕俯仰 |
| 左摇杆 纵向 `ly` | 腕旋转 |

## 2.2 按键定义

| 位 | 名称 | 功能 |
|---|---|---|
| bit0 | 急停 | 底盘与机械臂停止输出 |
| bit1 | 夹爪 | 张开与闭合状态切换 |
| bit2 | 模式 | 1 = 机械臂模式，0 = 底盘模式 |
| bit3 | 对孔 | 机械臂顺序归位 |
| bit4 | 取矿 | 执行取矿动作序列 |
| bit5 | 放矿 | 执行放矿动作序列 |

## 2.3 工作模式

系统包含底盘模式与机械臂模式，由 bit2 切换。

| 切换方向 | 系统响应 |
|---|---|
| 底盘 → 机械臂 | 底盘停止输出，机械臂进入可操作状态 |
| 机械臂 → 底盘 | 机械臂停止输出，正在执行的预设动作同步终止 |

# 三、启动流程

## 3.1 上电时序

| 顺序 | 系统行为 |
|---|---|
| 1 | 状态指示灯熄灭 |
| 2 | 显示单元点亮，输出电压、电流、功率、电量 |
| 3 | 机械臂按 夹爪 → 腕旋转 → 腕俯仰 → 大臂 → 小臂 顺序归位 |
| 4 | 无线链路建立，状态指示灯常亮 |
| 5 | 底盘驱动使能，进入待命状态 |

## 3.2 状态指示

| 指示状态 | 系统状态 |
|---|---|
| 熄灭 | 无线链路未建立 |
| 常亮 | 链路正常，系统可操作 |
| 慢闪（0.5 s 周期） | 急停状态 |

---

# 四、底盘控制

## 4.1 运动方式

系统采用麦克纳姆轮全向底盘，支持三自由度平面运动。

| 操作 | 运动形式 |
|---|---|
| 右摇杆 纵向 | 沿车头方向直行或倒车 |
| 右摇杆 横向 | 保持车头朝向的左右平移 |
| 左摇杆 横向 | 原地旋转 |
| 组合操作 | 平移与旋转合成运动 |

## 4.2 停止条件

| 条件 | 响应 |
|---|---|
| 摇杆回中 | 目标速度归零，按减速曲线停止 |
| 急停按键触发 | 立即停止 |
| 无线链路中断 | 立即停止 |
| 切换至机械臂模式 | 立即停止 |

## 4.3 控制参数

| 参数 | 数值 |
|---|---|
| 最大前进速度 | 0.50 m/s |
| 最大平移速度 | 0.50 m/s |
| 最大旋转速度 | 1.50 rad/s |
| 单轮速度上限 | 750 mm/s |
| 控制周期 | 20 ms |
| 速度环增益 | kp = 4.0，ki = 2.0，kd = 0 |
| 前馈系数 | 1.25 |
| 目标速度死区 | 5 mm/s |
| 轮组直径 | 60 mm |
| 编码器分辨率 | 1560 计数 / 圈 |

# 五、机械臂控制

## 5.1 关节定义

| 关节 | 索引 | 通道 | 行程（µs） | 原点（µs） |
|---|---|---|---|---|
| 大臂 | 0 | ch1 | 1420 ~ 2500 | 1420 |
| 小臂 | 1 | ch4 | 700 ~ 2500 | 700 |
| 腕俯仰 | 2 | ch2 | 500 ~ 2500 | 1520 |
| 腕旋转 | 3 | ch3 | 500 ~ 2500 | 2500 |
| 夹爪 | 4 | ch0 | 500 ~ 1600 | 1500 |

通道编号与驱动板上 LED 标号一致。

## 5.2 摇杆控制规则

系统对四个摇杆轴采用单轴选择控制：

| 规则 | 说明 |
|---|---|
| 轴选择 | 取绝对值最大的摇杆轴，其余三个关节保持当前位置 |
| 切换阈值 | 当前关节幅值不低于最大值的 85% 时维持当前选择 |
| 腕旋转死区 | 左摇杆纵向幅值低于 350 时腕旋转不动作 |

## 5.3 关节运动参数

| 关节 | 角速度 | 角加速度 |
|---|---|---|
| 大臂 | 40 °/s | 300 °/s² |
| 小臂 | 40 °/s | 300 °/s² |
| 腕俯仰 | 40 °/s | 500 °/s² |
| 腕旋转 | 60 °/s | 500 °/s² |
| 夹爪 | 90 °/s | 800 °/s² |

## 5.4 夹爪控制

| 状态 | 脉宽 |
|---|---|
| 张开 | 1500 µs |
| 闭合 | 650 µs |

由 bit1 切换，单程时间约 0.85 s。

## 5.5 预设动作

预设动作按关节依次执行，单个关节动作完成后进入下一关节。执行期间摇杆输入不生效，其余预设按键不响应。切换模式、触发急停或链路中断时动作终止。

三个预设动作均不改变夹爪状态。

### 对孔（bit3）

| 步骤 | 关节 | 目标 |
|---|---|---|
| 1 | 腕旋转 | 2500 µs |
| 2 | 腕俯仰 | 1520 µs |
| 3 | 大臂 | 1420 µs |
| 4 | 小臂 | 700 µs |

### 取矿（bit4）

| 步骤 | 关节 | 目标 |
|---|---|---|
| 1 | 腕旋转 | 2500 µs |
| 2 | 腕俯仰 | 500 µs |
| 3 | 小臂 | 1300 µs |
| 4 | 大臂 | 2000 µs |
| 5 | 小臂 | 2300 µs |

### 放矿（bit5）

| 步骤 | 关节 | 目标 |
|---|---|---|
| 1 | 小臂 | 1850 µs |
| 2 | 大臂 | 1420 µs |
| 3 | 腕俯仰 | 2350 µs |
| 4 | 腕旋转 | 2500 µs |

# 六、显示单元

显示单元按 200 ms 周期刷新，输出四行信息。

| 行 | 内容 | 单位 |
|---|---|---|
| 1 | 电池电压 | V |
| 2 | 放电电流 | A |
| 3 | 功率 | W |
| 4 | 剩余电量 | % |

剩余电量由电压经一阶低通滤波后查表插值得到。

# 七、无线通信

| 参数 | 数值 |
|---|---|
| 收发芯片 | SI24R1（兼容 nRF24L01+） |
| 通信信道 | 82（2482 MHz） |
| 空中速率 | 1 Mbps |
| 发射功率 | 0 dBm |
| 校验方式 | CRC 16 位 |
| 通信地址 | 0A 01 06 1E 01 |
| 负载长度 | 17 字节 |
| 自动应答 | 启用 |
| 链路超时 | 200 ms |

遥控器端通信信道须与车体一致。

# 八、调试接口

## 8.1 调试变量

| 变量 | 所在文件 | 说明 |
|---|---|---|
| `g_motor_en` | motor_task.c | 底盘驱动使能 |
| `g_motor_mode` | motor_task.c | 0 停止 / 1 开环 / 2 单轮闭环 / 3 运动学 / 4 遥控 |
| `g_test_duty[4]` | motor_task.c | 开环占空比 |
| `g_test_speed` | motor_task.c | 单轮闭环目标速度（mm/s） |
| `g_cmd_vx` / `g_cmd_vy` / `g_cmd_wz` | motor_task.c | 车体速度指令 |
| `g_enc_count[4]` | encode.c | 编码器累计计数 |
| `g_enc_speed[4]` | encode.c | 实测轮速（mm/s） |
| `g_pid_kp/ki/kd[4]` | controller.c | 速度环增益 |
| `g_pid_ff[4]` | controller.c | 前馈系数 |
| `g_arm_mode` | arm_task.c | 0 遥控 / 1 脉宽调试 / 2 角度调试 |
| `g_test_us[5]` | arm_task.c | 脉宽调试目标 |
| `g_test_deg10[5]` | arm_task.c | 角度调试目标（0.1°） |

## 8.2 调试模式

| 模式值 | 功能 |
|---|---|
| 0 | 遥控控制 |
| 1 | 直接输出 `g_test_us` 指定脉宽 |
| 2 | 按 `g_test_deg10` 指定角度运动 |

## 8.3 串口调试

串口默认关闭。启用方式：

```c
// user/common/debug.h
#define DEBUG_ENABLE    1

// user/app/arm_debug.h
#define ARM_DEBUG       1
```

接口参数：USART2，115200，8N1。
